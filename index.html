THE MISSING DIAGNOSTIC

A model can read T—and still misunderstand the physics.

Answer accuracy collapses recognition, role assignment, and downstream reasoning into one outcome. PhysAlign tests the earlier question directly: did the model attach the observed content to the physical entity or relation supported by the problem?

Each query preserves the original diagram and conditions, points to one evidence location, and asks for the local physical correspondence.

SIX SOURCES · SEVEN DOMAINS

Broad evidence, precisely localized.

04 / DATASET

PhysAlign keeps each probe attached to the full original problem while localizing the evidence that defines the query.

Source datasets
SeePhys, LiveK12Bench, PhysElite, OlympiadBench, Gaokao-MM-Physics, and PhyX-OE.
Evaluation unit
A parent physics problem plus one localized evidence–role query.
Quality control
Answer-blind observation, human review, structural checks, and separated public/private records.

Coverage is intentionally reported as descriptive, not domain-balanced.
